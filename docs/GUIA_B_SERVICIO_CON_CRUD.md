# G2 - Microservicio con CRUD simple

*Guía de práctica - 2026 - siguiendo el código de las sesiones de Pagatu*

## 1. Introducción

### 1.1 Qué vas a construir

Al servicio de la [G1](GUIA_A_SERVICIO_SIN_CRUD.md) le agregas un **CRUD de libros** (listar, agregar, editar, eliminar)
escrito **igual que el CRUD de categorías de Pagatu** ([S1](https://262dist.github.io/pagatu/sesiones/S01_Construccion_Servicio_Base/)):
entidad, DTO `Request`/`Response`, **mapper con MapStruct**, repositorio, servicio, controlador y manejo de errores.
Además, cada cambio se avisa por Kafka (`libro.creado`, `libro.actualizado`, `libro.eliminado`).

El frontend sigue el patrón de `features/catalogo` de Pagatu ([S11](https://262dist.github.io/pagatu/sesiones/S11_Integracion_Cliente_Frontend_Angular_Keycloak/)):
**model + service + lista + formulario**, sin diseño.

> **Requisito**
> Haz primero la [G1 - Microservicio sin CRUD](GUIA_A_SERVICIO_SIN_CRUD.md) completa.

### 1.2 Adáptalo a lo que pida el profe

Además de los reemplazos de la G1 (`biblioteca` → tu servicio), aquí reemplazas el **recurso**:

| En la guía dice | 👉 Lo cambias por (ej. el profe pide "Pagos") |
|---|---|
| `Libro` | `Pago` (clase Java, singular, con mayúscula) |
| `libro` | `pago` (variables y archivos del frontend) |
| `libros` | `pagos` (tabla y ruta, plural) |
| campos `titulo`, `autor` | los campos que pida el profe |

Cada campo aparece en: el **SQL** (2), la **entidad** (3.1), el **Request** y el **Response** (3.2),
el **servicio** en `actualizar` (3.6), y en el frontend: el **model** (5.1), el **formulario** (5.5 y 5.6) y la **tabla** (5.4).
Usa esta tabla para traducir cada campo:

| El profe dice... | SQL | Java | Validación (Request) | Input HTML |
|---|---|---|---|---|
| texto | `VARCHAR(150)` | `String` | `@NotBlank @Size(max = 150)` | `<input type="text" formControlName="x" />` |
| número entero | `INTEGER` | `Integer` | `@NotNull @Min(0)` | `<input type="number" formControlName="x" />` |
| decimal / dinero | `NUMERIC(10,2)` | `BigDecimal` | `@NotNull @DecimalMin("0.0")` | `<input type="number" step="0.01" formControlName="x" />` |
| fecha | `DATE` | `LocalDate` | `@NotNull` | `<input type="date" formControlName="x" />` |
| sí / no | `BOOLEAN NOT NULL DEFAULT true` | `Boolean` | — | `<input type="checkbox" formControlName="x" />` |

## 2. La tabla: `src\main\resources\db\migration\V1__create_libros.sql`

Mismo estilo que `V1__create_catalogo_tables.sql` del profe.

```sql
CREATE TABLE IF NOT EXISTS libros (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY,
    titulo VARCHAR(150) NOT NULL,
    autor VARCHAR(100),
    PRIMARY KEY (id)
);
```

> **Nunca edites una migración ya aplicada**
> Si ya corriste el servicio y quieres cambiar la tabla, crea `V2__...sql`
> (ej. `ALTER TABLE libros ADD COLUMN anio INTEGER;`). Si editas el `V1`, Flyway falla con `Migration checksum mismatch`.

```java
package pe.edu.upeu.lamb.biblioteca.exception;

import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.time.Instant;
import java.util.HashMap;
import java.util.Map;

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<Map<String, Object>> handleNotFound(ResourceNotFoundException ex) {
        Map<String, Object> body = new HashMap<>();
        body.put("timestamp", Instant.now().toString());
        body.put("status", HttpStatus.NOT_FOUND.value());
        body.put("error", "Not Found");
        body.put("message", ex.getMessage());
        return ResponseEntity.status(HttpStatus.NOT_FOUND).body(body);
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<Map<String, Object>> handleValidation(MethodArgumentNotValidException ex) {
        Map<String, Object> body = new HashMap<>();
        body.put("timestamp", Instant.now().toString());
        body.put("status", HttpStatus.BAD_REQUEST.value());
        body.put("error", "Bad Request");
        body.put("message", "Error de validación en los datos enviados");
        return ResponseEntity.status(HttpStatus.BAD_REQUEST).body(body);
    }
}
```

### 3.6 `service\LibroService.java`

Como `CategoriaService` de Pagatu (`listar`, `obtener`, `crear`, `actualizar`, `eliminar`, `buscarOFallar`),
y además avisa cada cambio por Kafka con el productor de la G1.

```java
package pe.edu.upeu.lamb.biblioteca.service;

import lombok.RequiredArgsConstructor;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import pe.edu.upeu.lamb.biblioteca.dto.LibroRequest;
import pe.edu.upeu.lamb.biblioteca.dto.LibroResponse;
import pe.edu.upeu.lamb.biblioteca.entity.Libro;
import pe.edu.upeu.lamb.biblioteca.event.BibliotecaEvento;
import pe.edu.upeu.lamb.biblioteca.exception.ResourceNotFoundException;
import pe.edu.upeu.lamb.biblioteca.mapper.LibroMapper;
import pe.edu.upeu.lamb.biblioteca.messaging.BibliotecaEventosProducer;
import pe.edu.upeu.lamb.biblioteca.repository.LibroRepository;

import java.time.Instant;
import java.util.List;

@Service
@RequiredArgsConstructor
public class LibroService {

    private final LibroRepository libroRepository;
    private final LibroMapper libroMapper;
    private final BibliotecaEventosProducer producer;

    @Value("${spring.application.name}")
    private String nombreServicio;

    public List<LibroResponse> listar() {
        return libroRepository.findAll().stream()
                .map(libroMapper::toResponse)
                .toList();
    }

    public LibroResponse obtener(Long id) {
        return libroMapper.toResponse(buscarOFallar(id));
    }

    @Transactional
    public LibroResponse crear(LibroRequest request) {
        Libro libro = libroRepository.save(libroMapper.toEntity(request));
        publicar("libro.creado", libro);
        return libroMapper.toResponse(libro);
    }

    @Transactional
    public LibroResponse actualizar(Long id, LibroRequest request) {
        Libro libro = buscarOFallar(id);
        libro.setTitulo(request.getTitulo());
        libro.setAutor(request.getAutor());
        libro = libroRepository.save(libro);
        publicar("libro.actualizado", libro);
        return libroMapper.toResponse(libro);
    }

    @Transactional
    public void eliminar(Long id) {
        Libro libro = buscarOFallar(id);
        libroRepository.delete(libro);
        publicar("libro.eliminado", libro);
    }

    private Libro buscarOFallar(Long id) {
        return libroRepository.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("Libro no encontrado: " + id));
    }

    private void publicar(String tipoEvento, Libro libro) {
        producer.publicarTrasCommit(BibliotecaEvento.builder()
                .tipoEvento(tipoEvento)
                .id(libro.getId())
                .mensaje(libro.getTitulo())
                .origen(nombreServicio)
                .timestamp(Instant.now().toEpochMilli())
                .build());
    }
}
```

> **👉 En `actualizar`**
> Pon un `libro.setX(request.getX());` por **cada** campo.

### 3.7 `controller\LibroController.java`

Como `CategoriaController` de Pagatu.

| Método | Ruta | Responde |
|---|---|---|
| `GET` | `/api/v1/libros` | `200` lista |
| `GET` | `/api/v1/libros/{id}` | `200` o `404` |
| `POST` | `/api/v1/libros` | `201` o `400` |
| `PUT` | `/api/v1/libros/{id}` | `200`, `400` o `404` |
| `DELETE` | `/api/v1/libros/{id}` | `204` o `404` |

```java
package pe.edu.upeu.lamb.biblioteca.controller;

import jakarta.validation.Valid;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.http.HttpStatus;
import org.springframework.web.bind.annotation.*;
import pe.edu.upeu.lamb.biblioteca.dto.LibroRequest;
import pe.edu.upeu.lamb.biblioteca.dto.LibroResponse;
import pe.edu.upeu.lamb.biblioteca.service.LibroService;

import java.util.List;

@Slf4j
@RestController
@RequestMapping("/api/v1/libros")
@RequiredArgsConstructor
public class LibroController {

    private final LibroService libroService;

    @GetMapping
    public List<LibroResponse> listar() {
        log.info("Listando libros");
        return libroService.listar();
    }

    @GetMapping("/{id}")
    public LibroResponse obtener(@PathVariable Long id) {
        return libroService.obtener(id);
    }

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public LibroResponse crear(@Valid @RequestBody LibroRequest request) {
        return libroService.crear(request);
    }

    @PutMapping("/{id}")
    public LibroResponse actualizar(@PathVariable Long id, @Valid @RequestBody LibroRequest request) {
        return libroService.actualizar(id, request);
    }

    @DeleteMapping("/{id}")
    @ResponseStatus(HttpStatus.NO_CONTENT)
    public void eliminar(@PathVariable Long id) {
        libroService.eliminar(id);
    }
}
```

### 5.3 `libro-list.ts` (la tabla)

```ts
import { Component, OnInit, inject, signal } from '@angular/core';
import { HttpErrorResponse } from '@angular/common/http';
import { RouterLink } from '@angular/router';
import { LibroService } from './libro-service';
import { Libro } from './libro.model';

@Component({
  selector: 'app-libro-list',
  imports: [RouterLink],
  templateUrl: './libro-list.html',
})
export class LibroList implements OnInit {
  private readonly libroService = inject(LibroService);
  protected readonly libros = signal<Libro[]>([]);
  protected readonly cargando = signal(true);
  protected readonly error = signal<string | null>(null);
  protected readonly errorAccion = signal<string | null>(null);

  ngOnInit(): void {
    this.cargar();
  }

  private cargar(): void {
    this.cargando.set(true);
    this.libroService.listar().subscribe({
      next: (data) => {
        this.libros.set(data);
        this.cargando.set(false);
      },
      error: () => {
        this.error.set('No se pudo cargar la lista de libros.');
        this.cargando.set(false);
      },
    });
  }

  eliminar(id: number): void {
    if (!confirm(`¿Seguro que quieres eliminar el libro ${id}?`)) {
      return;
    }
    this.errorAccion.set(null);
    this.libroService.eliminar(id).subscribe({
      next: () => this.cargar(),
      error: (err: HttpErrorResponse) => {
        this.errorAccion.set(
          err.status === 403 ? 'No tienes permiso para esta acción.' : 'No se pudo eliminar el libro.',
        );
      },
    });
  }
}
```

### 5.5 `libro-form.ts` (agregar y editar con el mismo formulario)

Si la ruta trae `:id`, carga el libro y al guardar hace `PUT`; si no, hace `POST`.

```ts
import { Component, inject, signal } from '@angular/core';
import { ActivatedRoute, Router } from '@angular/router';
import { FormBuilder, ReactiveFormsModule, Validators } from '@angular/forms';
import { HttpErrorResponse } from '@angular/common/http';
import { LibroService } from './libro-service';

@Component({
  selector: 'app-libro-form',
  imports: [ReactiveFormsModule],
  templateUrl: './libro-form.html',
})
export class LibroForm {
  private readonly fb = inject(FormBuilder);
  private readonly libroService = inject(LibroService);
  private readonly route = inject(ActivatedRoute);
  private readonly router = inject(Router);

  protected readonly id = signal<number | null>(null);
  protected readonly cargando = signal(false);
  protected readonly error = signal<string | null>(null);

  protected readonly form = this.fb.nonNullable.group({
    titulo: ['', [Validators.required, Validators.maxLength(150)]],
    autor: ['', [Validators.maxLength(100)]],
  });

  constructor() {
    const idParam = this.route.snapshot.paramMap.get('id');
    if (idParam) {
      const id = Number(idParam);
      this.id.set(id);
      this.cargando.set(true);
      this.libroService.obtener(id).subscribe({
        next: (libro) => {
          this.form.patchValue(libro);
          this.cargando.set(false);
        },
        error: () => {
          this.error.set('No se pudo cargar el libro.');
          this.cargando.set(false);
        },
      });
    }
  }

  guardar(): void {
    if (this.form.invalid) {
      this.form.markAllAsTouched();
      return;
    }
    const valor = this.form.getRawValue();
    const id = this.id();
    const peticion = id ? this.libroService.actualizar(id, valor) : this.libroService.crear(valor);

    peticion.subscribe({
      next: () => this.router.navigate(['/biblioteca/libros']),
      error: (err: HttpErrorResponse) => {
        this.error.set(
          err.status === 403 ? 'No tienes permiso para esta acción.' : 'No se pudo guardar el libro.',
        );
      },
    });
  }

  cancelar(): void {
    this.router.navigate(['/biblioteca/libros']);
  }

  protected mensajeValidacion(campo: 'titulo' | 'autor'): string {
    const control = this.form.controls[campo];

    if (!control.touched) return '';
    if (control.hasError('required')) return 'Este campo es obligatorio.';
    if (control.hasError('maxlength')) {
      return `Máximo ${control.getError('maxlength').requiredLength} caracteres.`;
    }
    return '';
  }
}
```

```ts
    loadComponent: () => import('./features/biblioteca/libro-form').then((m) => m.LibroForm)
  },
```

## 8. ¿El profe pide 2 o más CRUD en el mismo servicio?

Repite **2 → 5** con el otro recurso (ej. `Prestamo`): `V2__create_prestamos.sql`, entidad, DTOs, mapper,
repositorio, servicio, controlador (`/api/v1/prestamos`), una ruta nueva en el Gateway (`lamb-biblioteca-prestamos`),
sus reglas en el `SecurityConfig` y sus archivos en el frontend. Las clases de la G1 y las `exception` se reutilizan.

## 9. Problemas comunes

| Síntoma | Solución |
|---|---|
| `LibroMapperImpl` no existe / `No qualifying bean of type LibroMapper` | Falta el `mapstruct-processor` en el `pom.xml` (3.3) |
| `Schema-validation: missing table [libros]` | Falta el `V1__create_libros.sql` o está en otra carpeta |
| `Schema-validation: wrong column type` | El tipo Java no coincide con el SQL (tabla 1.2) |
| `Migration checksum mismatch` | Editaste una migración aplicada: crea `V2__...sql` |
| `403` al guardar | Entraste con un usuario sin `ADMIN` (4.2) |
| `404` en `/api/v1/libros` por el Gateway | Falta la ruta 4.1 o no reiniciaste el Gateway |
